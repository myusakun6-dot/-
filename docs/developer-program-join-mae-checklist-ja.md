## 2. 印刷品質（加入前に完了）

## 3. iOSプロジェクト整備（加入前に完了）
- [ ] `MockMakerApp` のSwiftファイル重複がない（RootViewController/Bridge/StoreKit等のみ）

- [ ] シミュレータで起動して白画面にならない
- [ ] 主要画面遷移でクラッシュしない
