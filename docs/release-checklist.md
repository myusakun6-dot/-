# リリース前チェック（自作模試メーカー）

## 1. 機能
- [ ] 問題作成（4択/穴埋め/記述）が保存される
- [ ] 模試作成→一覧→受験開始→採点まで完走できる
- [ ] 暗記モードで回答後に答え表示できる
- [ ] 印刷（問題用/解答用）がプレビュー通りに出力される
- [ ] 共有コードの作成/取込が成功する

### 通し確認の実行順（シミュレータ）
1. 作成タブで4択1問・穴埋め1問・記述1問を追加して再起動後も残ることを確認
2. 模試タブで新規作成→問題選択→保存→受験開始→終了して採点まで実行
3. ホームの最近の結果を開き、各問題の「問題/回答/正答/判定（正解・不正解）」が見えることを確認
4. 暗記タブで開始→回答→答え表示→終了して結果表示まで実行
5. 印刷タブで問題用/解答用を切替し、プレビューと印刷ダイアログの内容が一致することを確認
6. 模試共有で共有コードを発行し、取込で同じ模試が復元されることを確認
